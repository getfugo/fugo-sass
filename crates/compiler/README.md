# fugo-sass-compiler

This crate exposes the internals of the main package, [`fugo-sass`](https://crates.io/crates/fugo-sass). For most users, the preferred crate should be `fugo-sass`, as it is more stable and has a simpler API.

This crate will see frequent breaking changes.

fugo-sass is a fork of [grass](https://github.com/connorskees/grass); this crate was `grass_compiler`.
